2find()로 영화 찾기

find()를 사용하여 제목이 "인터스텔라"인 영화를 찾아 주세요. 찾은 영화는 foundMovie 변수에 저장합니다. 그리고 영화의 제목과 평점을 Console에 출력합니다.

결과
인터스텔라의 평점은 8.7점입니다.
힌트
movies.find((movie) => {
  // 조건
});

find()는 조건을 만족하는 첫 번째 요소 하나를 반환합니다.

3filter()로 평점이 높은 영화 찾기

filter()를 사용하여 평점이 8.5 이상인 영화만 찾아 주세요. 결과는 새로운 배열에 저장하고 Console에 출력합니다.

결과
[
  { title: "인터스텔라", voteAverage: 8.7 },
  { title: "다크 나이트", voteAverage: 9 }
]
힌트
movies.filter((movie) => {
  // voteAverage가 8.5 이상인지 확인
});

filter()는 조건을 만족하는 요소들을 모아 새로운 배열을 반환합니다.
변수 이름은 해설 코드와 달라도 괜찮습니다.

4map()으로 영화 제목만 가져오기

map()을 사용하여 모든 영화의 제목만 들어있는 새로운 배열을 만들어 주세요.

결과
["인셉션", "인터스텔라", "다크 나이트", "테넷"]
힌트
movies.map((movie) => {
  // 각 movie에서 필요한 값을 반환
});

기존 movies는 여러 영화가 들어있는 배열이므로 복수형으로 작성되어 있습니다. 콜백 함수의 movie는 그중 영화 하나를 의미하므로 단수형을 사용합니다. 변환한 결과 역시 여러 제목이 들어있는 배열이므로 movieTitles처럼 복수형으로 작성할 수 있습니다.

7AI를 활용하여 오늘 배운 내용 복습하기

과제를 먼저 직접 완료한 뒤 작성한 코드를 AI에게 검토받습니다. 다음 프롬프트에 자신의 코드를 추가하여 질문해 보세요.

나는 JavaScript를 처음 배우고 있으며 오늘 다음 내용을 배웠어. - find() - filter() - map() - trim() - toLowerCase() 아래는 오늘 과제로 내가 직접 작성한 코드야. [내 코드 붙여넣기] 정답 코드를 새로 작성하지 말고 다음 내용을 검토해줘. 1. 하나의 요소를 찾을 때 find()를 적절하게 사용했는지 2. 조건에 맞는 여러 요소를 찾을 때 filter()를 적절하게 사용했는지 3. 배열의 요소를 변환할 때 map()을 적절하게 사용했는지 4. trim()과 toLowerCase()의 반환값을 올바르게 사용했는지 5. Form에서 Input의 값을 올바르게 가져와 가공했는지 6. 오늘 배운 범위를 벗어나 불필요하게 복잡하게 작성한 부분이 있는지 문제가 있다면 정답 코드를 바로 보여주지 말고 문제가 있는 부분과 이유, 수정할 수 있도록 힌트만 알려줘.

AI의 피드백을 확인한 뒤 필요한 부분은 직접 수정하고 다시 실행하여 결과를 확인합니다.

제출 전 체크리스트

  • find()를 사용하여 조건에 맞는 영화 하나를 찾았다.
  • find()의 반환값을 사용하여 영화 정보를 출력했다.
  • filter()를 사용하여 조건에 맞는 영화들을 찾았다.
  • map()을 사용하여 영화 제목만 들어있는 새로운 배열을 만들었다.
  • Form의 Submit Event를 처리했다.
  • preventDefault()를 사용하여 Form의 기본 동작을 막았다.
  • .value를 사용하여 Input의 값을 가져왔다.
  • trim()을 사용하여 문자열의 앞뒤 공백을 제거했다.
  • toLowerCase()를 사용하여 영문자를 소문자로 변경했다.
  • 가공한 검색어를 화면에 출력했다.
  • find(), filter(), map()의 용도를 구분했다.
  • Console에 오류가 없는지 확인했다.
  • AI의 피드백을 확인하고 필요한 부분을 직접 수정했다.
